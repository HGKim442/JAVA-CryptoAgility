# Java JCA/JCE 암호 전환 안전성 — Repeat2 독립 재현

## 개요

이 브랜치는 Java JCA/JCE 환경에서 암호 전환 시점의
오용과 PQC 다운그레이드를 실험하는 Repeat2 구현의
재현 자료입니다.

기존 2026-10-10 패키지를 출처로 하되,
2026-11-02 WSL Ubuntu 및 Temurin JDK 17 환경에서
E1/PQC 실험을 별도로 실행해 결과를 확인했습니다.

## 검증된 실험

| 항목 | 이번 재현 결과 |
|---|---|
| Java 17 엄격 빌드 | 통과 |
| E1 공격 진단 | 540행 |
| E1 정상 비용 | 900행 |
| PQC 실패 실험 | 36행 |
| 공개 증거 파일 | 24개 |
| 증거 SHA-256 | 24/24 일치 |

### E1

- VULNERABLE: 6개 합성 시나리오 모두 공격 효과 관측
- ALLOWLIST: 01·02 차단, 03~06 공격 효과 관측
- PROPOSED: 6개 시나리오 모두 차단

### PQC 실패

두 실패 조건에서 VULNERABLE 및 ALLOWLIST는
X25519 단독 폴백을 기록했고, PROPOSED는
정책 거부를 기록했습니다.

## 실행 환경

- Linux/WSL
- Temurin JDK 17
- Python 3
- Bouncy Castle bcprov-jdk18on 1.86

외부 JAR 파일은 저장소에 포함하지 않습니다.
의존성 확보와 실행 방법은 docs/REPRODUCTION.md를 참고하세요.

## 재현 명령

bash scripts/reproduce-e1-pqc.sh

## 증거

- evidence/e1/: E1 공격 및 정상 비용 원자료
- evidence/pqc/: PQC 실패 실험 원자료
- SHA256SUMS_EVIDENCE.txt: 공개 증거 파일 해시

## 연구 한계 및 출처

이 결과는 제공된 구현과 합성 실험 시나리오를
동일 코드로 재실행한 결과입니다.

독립 구현에 의한 교차 검증이나 실제 서비스 공격 차단
검증으로 해석하지 않습니다.

PQC 실험은 실제 ML-KEM-768 및 X25519 연산을
포함하지만 합성 HMAC 결합기를 사용하므로
표준 하이브리드 프로토콜 검증은 아닙니다.

기존 패키지에 포함된 미재현 성능 측정 및
JDK 24 결과는 이번 재현 완료 범위에서 제외합니다.

기존 패키지의 실행 주체와 이력은 별도로 확인되지
않았으므로, 과거 기록을 이번 직접 수행 결과로
표기하지 않습니다.
